# Project & Toko Summary Generator

## 1. Overview
Generator ringkasan proyek otomatis yang mengumpulkan metrik dari puluhan catatan sprint, task, invoice, dan inventaris toko ke dalam satu halaman laporan eksekutif berkala (mingguan/bulanan).

## 2. Key Capabilities (Backlog)
- **Multi-File Rollup**: Mengagregasi metrik dari frontmatter seluruh file dalam virtual folder atau scope tertentu.
- **Automated KPI Cards**: Menghasilkan kartu rekap total pendapatan, tugas terselesaikan, dan deadline terdekat dalam format Markdown rapi.
- **One-Click Regenerate**: Memperbarui angka-angka rekap secara instan ketika ada note yang berubah.

## 3. Integration Points
- Terhubung dengan Virtual Folder Tree dan Todolist Scanner.

## 4. Status: -1 (Backlog)
Masuk dalam backlog antrean fitur reporting dan analytics.
