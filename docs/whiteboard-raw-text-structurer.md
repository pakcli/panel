# Whiteboard & Raw Text Structurer

## 1. Overview
Alat bantu transformasi teks coretan kasar (*scratchpad / braindump*) menjadi struktur dokumen terorganisasi dengan heading, bullet points, dan blok metadata otomatis.

## 2. Key Capabilities (Backlog)
- **Heuristic Sectioning**: Mengidentifikasi baris-baris ide utama dan memformatnya menjadi heading level 2 atau 3 secara otomatis.
- **Task & Spec Conversion**: Mengubah tanda strip atau simbol tidak baku menjadi checklist tugas dan property frontmatter standar.
- **Split Clean-up View**: Menampilkan teks mentah di sebelah kiri dan hasil penataan bersih di sebelah kanan sebelum disimpan.

## 3. Integration Points
- Terintegrasi dengan editor view dan modul Deep Writing.

## 4. Status: -1 (Backlog)
Fitur berada dalam backlog antrean asisten penataan ide.
