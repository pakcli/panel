# Multi-Format Exporter (Markdown, CSV, JSON)

## 1. Overview
Mesin pengekspor dokumen dan kumpulan catatan virtual ke dalam berbagai format standar industri (Markdown murni tanpa wikilinks kustom, CSV datar, atau payload JSON terstruktur).

## 2. Key Capabilities (Backlog)
- **Wikilink to Standard Markdown**: Mengubah wikitext `[[Catatan]]` menjadi link standar `[Catatan](Catatan.md)` untuk kompatibilitas di luar Obsidian.
- **Tabular Flattening**: Mengekspor kumpulan catatan spec/frontmatter menjadi file spreadsheet CSV.
- **Full JSON Bundle**: Mengemas hirarki folder virtual dan isi dokumen ke dalam satu file JSON untuk migrasi ke platform lain.

## 3. Integration Points
- Terintegrasi dengan Virtual Folder Tree.

## 4. Status: -1 (Backlog)
Fitur berada dalam backlog antrean pengembangan utilitas ekspor data.
