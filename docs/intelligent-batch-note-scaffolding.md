# Intelligent Batch Note Scaffolding & Folderize Converter

## 1. Overview
Generator pembuatan kumpulan dokumen banyak sekaligus (*bulk generator*) dari daftar teks multi-baris serta alat konversi cepat note tunggal menjadi struktur folder dengan index note terkelola.

## 2. Key Capabilities (Backlog)
- **Batch Text-to-Notes**: Memasukkan daftar judul baris per baris dan menghasilkan puluhan file note secara instan dengan boilerplate YAML frontmatter yang sesuai.
- **Smart Folderize**: Mengubah file `Proposal.md` menjadi direktori `Proposal/` dengan file `index.md` dan memindahkan aset terkait ke dalamnya.
- **Template Schema Expansion**: Mengisi nilai default variabel template (tanggal, UUID, autor, tag) secara otomatis saat scaffolding dibuat.

## 3. Integration Points
- Terhubung dengan Virtual Folder Tree untuk penempatan lokasi virtual dan fisik.
