# Dual-Asset Image Comparison Viewer (Slider Split Compare)

## 1. Overview
Komponen peninjau gambar komparatif berbasis split-slider horizontal/vertikal untuk membandingkan dua versi gambar (misal versi original sebelum diedit vs versi tersensor/retouched) secara real-time.

## 2. Key Capabilities (Planned)
- **Interactive Split Handle**: Slider geser interaktif untuk mengungkap perbedaan piksel per piksel antara Asset A dan Asset B.
- **Synchronized Panning & Zoom**: Menyesuaikan koordinat pan dan zoom kedua gambar secara serentak.
- **Side-by-Side & Overlay Modes**: Pilihan mode peninjauan berdampingan atau tumpang tindih dengan transparansi blend.

## 3. Integration Points
- Akan diintegrasikan dengan modul `ImageTriageModal` dan data gambar dari plugin `local`.

## 4. Status: 0 (Planned / In Progress)
Spesifikasi arsitektur telah dirancang; sedang dijadwalkan untuk implementasi antarmuka slider interaktif.
