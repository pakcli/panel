# Dictionary & Item Definition Registry

## 1. Overview
Registri glosarium dan kamus definisi istilah teknis/item proyek yang memudahkan pembuatan dan pemanggilan definisi kata saat menulis dokumen naskah.

## 2. Key Capabilities (Backlog)
- **Central Term Registry**: Menyimpan indeks istilah, akronim, dan definisi dalam file kamus terpusat.
- **Hover Term Tooltip**: Menampilkan cuplikan definisi istilah saat kursor melayang di atas kata kunci di editor.
- **Auto-Backlink Generator**: Menghubungkan penyebutan istilah dengan catatan glosarium terkait secara otomatis.

## 3. Integration Points
- Terintegrasi dengan modul kamus frontmatter dan CodeMirror hover provider.

## 4. Status: -1 (Backlog)
Fitur berada dalam backlog antrean pengembangan knowledge tooling.
