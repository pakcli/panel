# Ribbon Organizer & Grouping Manager

## 1. Overview
Pengelola tata letak dan pengelompokan ikon ribbon sisi kiri Obsidian yang mengorganisasi ikon plugin ke dalam folder dropdown atau sub-grup rapi untuk mencegah ribbon meluap (*cluttered ribbon*).

## 2. Key Capabilities
- **Ribbon Grouping & Ordering**: Mengelompokkan ikon aksi ke dalam kategori logis (Media, Editor, Navigasi, Analytics).
- **Custom Icon Drag & Drop**: Mengubah urutan prioritas ikon ribbon sesuai preferensi alur kerja harian.
- **Auto-Detection**: Mendeteksi ikon ribbon yang didaftarkan oleh modul internal maupun plugin eksternal secara dinamis.

## 3. Integration Points
- Terintegrasi di `src/features/ribbon/` dan tab konfigurasi `RibbonManagerSettingTab`.

Fitur sudah diimplementasikan penuh dan aktif di `pakcli-panel`.
